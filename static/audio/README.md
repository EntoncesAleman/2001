# Música de la cutscene de apertura

Poné acá un archivo llamado `intro-musica.mp3` para que suene de fondo
durante la intro animada (`templates/index.html` ya lo referencia).

Si no hay ningún archivo, la cutscene funciona igual, simplemente sin
música — no rompe nada.

**Importante sobre derechos de autor:** no incluyas una copia (ni siquiera
en formato MIDI) de una canción comercial existente si vas a desplegar esto
en un sitio público, salvo que tengas los derechos para usarla. Una opción
es usar una pista instrumental original con una licencia libre (CC0,
Creative Commons con atribución, etc.) o encargar/componer algo original
inspirado en el estilo que quieras.
